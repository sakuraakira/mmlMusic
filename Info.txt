MML Music Player for Project Zomboid

A comprehensive music playing system using MML (Music Macro Language).

=== What does this mod do? ===

This mod allows players to play music in Project Zomboid using MML notation:

- Parse and play MML (Music Macro Language) notation
- Support multiple instruments (Piano, Guitar, Bass, Violin, Flute, etc.)
- Multi-track playback (up to 3 tracks simultaneously)
- In-game composition interface
- Sheet music item system
- Multiplayer support with sound range limitation
- Full MML syntax support: notes, octaves, tempo, velocity, tied notes, dotted notes, rests

=== Features ===

MML Syntax Support:
- Notes: C D E F G A B (H)
- Octaves: O (set), < (down), > (up)
- Length: L (default), numbers, dots (.)
- Tempo: T
- Velocity: V
- Tied notes: &
- Rests: R
- Absolute pitch: N

Instruments:
- Piano
- Guitar (Clean, Steel, Distortion)
- Bass Finger
- Violin
- Flute
- Saxophone
- Trumpet
- Synthesizer

Game Integration:
- Context menu for instruments
- Instrument UI for playing
- Composition UI for creating music
- Sheet music items that can be found or created
- Network synchronization for multiplayer

=== Technical Implementation ===

Core Modules:
- MMLParser.lua: Parses MML syntax into note sequences
- MMLPlayer.lua: Manages music playback and multi-track synchronization
- MusicPlayer.lua: Handles actual sound playback
- MMLInstrumentUI.lua: Provides in-game interface for playing instruments
- MMLComposeUI.lua: Provides in-game interface for composing music

=== Usage ===

1. Find or craft an instrument in-game
2. Right-click the instrument
3. Select "Play" from the context menu
4. Enter MML notation in the interface
5. Click play to hear your music!

Example MML:
  t120 l4 o4 cdefgab>c

Multi-track example (comma-separated):
  t120 l4 o4 cdefg, l4 o3 ccccg, l2 o2 cg
